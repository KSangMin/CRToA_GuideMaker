# 📝 Product Requirement Document (PRD)

## 1. Project Overview
- **Project Name**: 쿠키런 모험의 탑 - 딜 사이클(로테이션) 이미지 제작 툴
- **Target Platform**: WebGL (PC/Mobile 웹 브라우저 대응) 및 Unity Editor
- **Core Concept**: 유저가 쿠키런 모험의 탑 캐릭터들의 스킬 아이콘과 각종 특수 제어 슬롯(반복, 스왑, 범위 지정 등)을 사이클에 배치하고, 사이클 전체의 이름을 지정하여 고도화된 딜 사이클 공략 이미지를 PNG 파일로 보낼 수 있는 웹 도구 제작.

## 2. User Stories & Features (기능 요구사항)
- [~] **[CookieData & Asset 관리]** _(쿠키 SO 완료, 스킬 모델은 CookieData 내장 수준)_
  - [x] ScriptableObject를 활용해 쿠키 데이터(이름, ID, 초상화, 정렬 순서, 속성, 클래스, 공격 타입 등) 구조 설계하기
  - [ ] 스킬 데이터(이름, 아이콘, 스킬 유형 - 평타/특수/궁극기/대시/태그인 등) 확장 가능하게 구조화하기 _(현재: `SpriteType` 리스트 + `SkillType` enum, 독립 Skill SO·태그인 미구현)_
- [~] **[Addressables & Remote 에셋 로드 시스템]** _(매니저·Remote 프로필 완료, 운영·CORS 검증 별도)_
  - [x] 어드레서블 자산 시스템(Addressable Asset System)을 프로젝트에 도입 및 세팅하기
  - [ ] 쿠키 초상화 및 스킬 아이콘 스프라이트들을 그룹으로 묶고 원격 서버(콘텐츠 서버)에 빌드/배포하기 _(Remote URL 프로필 존재, 배포 파이프라인 미검증)_
  - [x] `Addressables.LoadAssetAsync` 또는 `DownloadDependenciesAsync`를 이용하여 런타임에 원격 서버로부터 쿠키 리소스를 동적으로 비동기 로드하는 매니저 구현하기
  - [ ] WebGL 환경에서 원격 카탈로그(Remote Catalog)를 정상적으로 업데이트하고 데이터를 캐싱하는 로직 구현하기 _(카탈로그 API 구현됨, CORS/캐시 정책 미기재)_
- [~] **[자유도 높은 사이클 에디터 구현]** _(행/열 사이클 레이아웃 + ScrollRect)_
  - [ ] 단순한 2차원 Grid/Layout 배열을 넘어 스킬 슬롯과 유저 커스텀 요소들이 결합할 수 있는 사이클 뷰 설계하기
  - [x] 전체 컨텐츠를 스크롤하여 볼 수 있는 가로/세로 ScrollRect 레이아웃 시스템 구축하기
- [~] **[스킬 슬롯 패널 및 드래그 앤 드롭 시스템]**
  - [x] 스크롤 뷰에 각 쿠키 패널 전부 삽입
  - [x] 각 쿠키 패널에 해당 쿠키의 정보 및 해당 쿠키의 스킬 슬롯 전부 삽입
  - [x] 패널 내 스킬 슬롯들을 드래그 앤 드롭하여 자유롭게 삽입 및 배치 전환이 가능하게 만들기
  - [ ] **[쿠키 스왑 슬롯]**: 딜 사이클 도중 특정 쿠키로 교체(Swap)됨을 알리는 슬롯 추가하기
- [x] **[특수 슬롯 패널 및 드래그 앤 드롭 시스템]**
  - [x] 스킬 슬롯 외에 '특수 기능 슬롯'들을 모아둔 독립된 사이드 패널 UI 만들기
  - [x] 패널 내 특수 슬롯들을 사이클 내부로 드래그 앤 드롭하여 자유롭게 삽입 및 배치 전환이 가능하게 만들기
  - [x] _(완료)_ 다형성(`Slot` 계층 구조) 적용 및 레이캐스트 버퍼 재사용 등 내부 최적화 적용
- [~] **[특수 슬롯 유형 세부 정의]**
  - [x] **[반복 슬롯]**: 특정 액션을 몇 번 반복할지 숫자를 지정(증감 버튼)하여 표시하는 기능 구현하기
  - [ ] **[영역 지정 컴포넌트]**: 사이클 특정 구간을 묶는 '시작 슬롯'과 '끝 슬롯' 쌍을 구현하고, 영역의 이름(예: 그로기 페이즈)을 타이핑해 달 수 있는 기능 구현하기
- [ ] **[슬롯 세부 편집 및 커스텀 각주]**
  - [ ] 사이클에 배치된 개별 슬롯 하단에 간단한 주석을 적을 수 있는 내장 인풋 뷰 연동하기
  - [ ] 특정 슬롯과 별개로 상단/하단에 유저가 원하는 대로 배치하여 타이핑하는 독립된 '각주 컴포넌트' 추가하기
- [ ] **[사이클 반복 및 연계 화살표 시스템]**
  - [ ] 특정 스킬 슬롯에서 다른 특정 스킬 슬롯으로 연결되는 '화살표 컴포넌트' 동적 생성 시스템 만들기
  - [ ] 사이클의 특정 구간 반복(Loop)이나 연계 흐름을 선과 화살표로 시각화하기
- [ ] **[사이클 전체 이름(타이틀) 지정 기능]**
  - [ ] 사이클 에디터 최상단에 사이클의 이름을 입력할 수 있는 메인 인풋 필드(`TMP_InputField`) 제공하기
  - [ ] 입력된 타이틀 텍스트가 이미지 보내기 시 최상단 타이틀 영역에 깔끔하게 포함되어 출력되도록 연동하기
- [~] **[세부 설정 컨트롤러]**
  - [ ] **[슬롯 간 거리]**: 사이클 내 아이콘들 사이의 간격(Spacing)을 슬라이더 등으로 제어하기
  - [~] **[슬롯 색상]**: 특정 스킬 유형이나 속성, 혹은 유저 선택에 따라 테두리/배경 색상을 변경하는 기능 구현하기 _(행 배경·폰트 색 피커만, 유형/속성 자동 색 없음)_
  - [x] **[한 열의 최대 슬롯 개수]**: 지정된 개수가 넘어가면 자동으로 다음 줄로 줄바꿈(Flexible Row 구조)되도록 제어하기
- [~] **[런타임 이미지 캡처]**
  - [ ] 유저가 지정한 타이틀, 모든 특수 슬롯, 각주, 화살표, 영역 가이드라인이 포함된 전체 사이클 영역(`RectTransform`) 지정하기 _(현재 `CycleVerticalLayout` 본문만 캡처)_
  - [x] 해당 영역만 화면 해상도 왜곡 없이 정확하게 `Texture2D`로 읽어와 PNG 바이너리로 변환하는 코루틴 작성하기
- [x] **[플랫폼별 이미지 다운로드]**
  - [x] PC/에디터 환경: 로컬 파일 시스템(`WriteAllBytes`)을 통해 즉시 저장하기
  - [x] WebGL 빌드 환경: JavaScript 플러그인(`.jslib`)과 연동되어 Base64 데이터 스트림을 통해 브라우저 다운로드 트리거하기

## 3. Edge Cases & Constraints (예외 케이스)
- **[원격 에셋 로딩 지연 및 다운로드 예외 처리]**: 네트워크 환경에 따라 Remote 서버에서 스프라이트를 불러오는 동안 유저에게 로딩 인디케이터(UI Spinner 등)를 보여주어야 하며, 로드 실패 시 디폴트 더미 아이콘으로 대체하여 에러로 인해 전체 UI가 멈추는 것을 방지할 것. _(부분: `UI_Loading`, `DefaultSpriteData` 폴백)_
- **[WebGL CORS 및 캐싱 이슈 대응]**: WebGL 웹 빌드에서 Remote 서버에 접근할 때 크로스 도메인(CORS) 에러가 발생하지 않도록 서버 설정을 구성하고, 브라우저 캐시로 인해 구버전 카탈로그를 참조하지 않도록 유의할 것.
- **[타이틀 글자 수 제한 및 UI 넘침 방지]**: 유저가 이름을 너무 길게 입력해도 캡처 영역을 벗어나지 않도록 글자 수 제한(Max Length)을 적용하고, TextMeshPro의 `Auto-Size` 기능을 활성화하여 폰트 크기가 유연하게 줄어들게 처리할 것.
- **[영역 지정 가이드라인의 동적 변동]**: 슬롯 간격이 바뀌거나 줄바꿈이 일어날 때 '시작 슬롯'과 '끝 슬롯'을 연결하는 하이라이트 박스의 범위를 재계산하고, 복수 행(줄바꿈 상태)으로 늘어나도 형태가 깨지지 않도록 Overlay UI 레이어에서 처리할 것.
- **[화살표 동적 갱신 및 앵커링 변동 대응]**: 특수 슬롯 삽입이나 레이아웃 변경으로 슬롯 위치가 바뀔 때, 화살표의 시작점/끝점 좌표를 실시간으로 재계산하고 줄바꿈 시 선이 꼬이지 않도록 로직을 안정화할 것.
- **[설정 변경에 따른 실시간 UI 재배치]**: 컨트롤러에서 슬롯 간격, 색상, 최대 개수를 조절하는 즉시 사이클 상의 Layout Group 및 구성요소 컴포넌트가 실시간으로 업데이트될 것. _(부분: 행 길이·색상 이벤트 반영, spacing 미구현)_
- **[메모리 및 가비지 컬렉션(GC) 최소화]**: 사용이 끝난 어드레서블 에셋은 적절히 `Release`할 것. _(부분: Addressables Release)_
- **[유연한 레이아웃 확장성]**: 줄바꿈 및 영역 박스, 각주 크기 변화로 인해 상하 폭이 늘어날 때 컨텐츠가 잘리지 않도록 `ContentSizeFitter`와 `LayoutGroup` 계층 구조를 최적화할 것.
- **[해상도 보존 및 웹 캡처 오류 대응]**: WebGL 환경의 웹 브라우저 창 크기 변화 시에도 캡처본 이미지 화질이 깨지거나 선이 어긋나지 않도록 픽셀 매핑(혹은 Render-to-Texture 전용 카메라 기법)을 구현할 것. _(부분: RenderTexture 캡처 구현, 브라우저 리사이즈 미검증)_

## 4. Release Criteria (완료 조건)
- [ ] 유니티 에디터 및 WebGL 빌드 환경에서 슬롯을 대량 배치해도 프레임 드랍이나 GC 스파이크가 발생하지 않을 것.
- [ ] Remote 서버의 네트워크 상태가 정상일 때 모든 쿠키와 스킬 에셋이 비동기로 완벽히 로드되어 사이클 및 선택 패널에 출력될 것. _(파이프라인 구현됨, WebGL 실환경 미확인)_
- [ ] 상단 인풋 필드의 타이틀 입력이 고정되어 있고, 슬롯 간격 및 줄바꿈 변경 시 각주와 반복 화살표가 실시간으로 완벽히 제자리를 찾아갈 것.
- [ ] 주요 웹 브라우저 WebGL 환경에서 테스트 시, 유저가 설정한 타이틀, 각주, 화살표, 영역 가이드라인이 모두 포함된 캡처본 PNG 파일이 깨짐 없이 로컬 드라이브에 정상 다운로드될 것. _(다운로드·본문 캡처 구현, 타이틀·오버레이 미포함)_
