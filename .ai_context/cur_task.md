# 📍 Current Task: 영역 지정 컴포넌트 (Area Slot) 개발 설계

## 🎯 Current Goal
- 딜 사이클 내에서 특정 범위를 묶어 영역의 이름을 타이핑하고 반투명 하이라이트 박스를 렌더링하는 영역 지정 컴포넌트를 설계한다.
- 각 행의 슬롯 수가 제각각인 불규칙 레이아웃에서 존재하지 않는 임의의 좌표(예: 2행 2열)에 가이드 라인이 침범하는 오작동을 차단하고, 실제 영역 내에 수집된 슬롯들의 부모 행(`CycleHorizontalLayout`) 단위로 가이드 라인을 쪼개어 실제 바운더리 내부만 수평선 조각을 그리는 **행 단위 좌표 한정 분할 렌더링(Row-Bounded Line Split Rendering)** 설계안의 최종 승인을 대기한다.

---

## 🌲 Proposed Hierarchy (씬 하이어라키 구조)

```txt
Canvas (UI Root)
└── CyclePanel (캡처 대상 RectTransform)
    └── Scroll View (또는 Content 래퍼)
        ├── CycleVerticalLayout (Vertical Layout Group - 물리 정렬)
        │   ├── CycleHorizontalLayout (Row 1)
        │   │   ├── CycleSlot (스킬 슬롯 1)
        │   │   └── ...
        │   └── ...
        └── AreaOverlayPanel (오버레이용 패널 - 최상단 렌더링)
        ├── AreaHighlightBox (영역 1 인스턴스 - AreaId="area_uuid_01" 매핑 렌더링)
        │   ├── ConnectingLines (수평 연결 가이드 라인 - Y-Offset: 15px 고정)
        │   │   ├── Line_Row2 (2행의 실재하는 슬롯 가이드라인 조각)
        │   │   └── Line_Row3 (3행의 실재하는 슬롯 가이드라인 조각)
        │   ├── StartBracket (상단 왼쪽 브래킷 ┌ - 높이: 10px 고정)
        │   ├── EndBracket (상단 오른쪽 브래킷 ┐ - 높이: 10px 고정)
        │   └── NameInputField (영역 이름 입력 텍스트박스)
        └── AreaHighlightBox (영역 2 인스턴스)
            └── ...
```
